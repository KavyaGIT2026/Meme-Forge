readme_content = """# MemeForge Gen Z 🔥🧢

An AI-powered, browser-based meme generator built for the modern era. MemeForge Gen Z lets you cook up highly relevant, hilarious memes using AI, search for classic templates, and even pull meme formats directly from YouTube. 

No backend required—just open the HTML file and start cooking! 🧑‍🍳

## ✨ Features

*   **🧠 AI "Cook" Mode:** Drop a keyword, scenario, or YouTube topic, and the app uses the LLaMA 3 AI model (via Groq) to write the perfect top/bottom text and generates a custom background image (via Pollinations AI).
*   **📺 YouTube Context Integration:** Connects to the YouTube Data API to pull real-world context (video titles, descriptions, views) to make your AI-generated memes hyper-relevant to current drama and trends.
*   **📦 Meme Finder (Discover):** Search through classic meme templates (via Imgflip) or search YouTube for specific video thumbnails to use as raw meme formats.
*   **✍️ Built-in Editor:** Add your own custom Impact-font Top Text and Bottom Text to any template or generated image.
*   **🗄️ The Vault:** Your personalized, locally-stored collection of memes. Save your masterpieces and download them directly to your device as PNGs.
*   **💅 Gen Z UI/UX:** Dark mode by default, smooth animations, Tailwind styling, and Lucide icons.

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
*   **Styling:** Tailwind CSS (via CDN)
*   **Icons:** Lucide Icons
*   **APIs Used:**
    *   [YouTube Data API v3](https://developers.google.com/youtube/v3) (Context & Template searching)
    *   [Groq API](https://groq.com/) / Llama 3 (Meme text generation)
    *   [Pollinations.ai](https://pollinations.ai/) (Image generation & AI text fallback)
    *   [Imgflip API](https://api.imgflip.com/) (Classic templates)
